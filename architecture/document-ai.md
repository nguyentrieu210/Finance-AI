# Document pipeline
Upload → quarantine → clean → parse/raster → layout/OCR → classify → structured candidate extraction → schema/semantic validation → human verification → evidence → matching/check. Async worker jobs fenced by revision/lease. PDF text layer not blindly trusted: reconcile visible raster where material discrepancy; DOCX/XLSX parsed without macros/external links; isolate converter/OCR with no egress, memory/CPU/page limits. No unapproved provider calls. Document kind unknown and multi-doc separation supported. Page locator uses original page index (1-based), bbox normalized 0..1 top-left after explicit rotation transform; spreadsheet sheet/cell, DOCX paragraph/table cell and rendered page when available. Preserve original bytes + hash. Candidate never authoritative merely by confidence; corrections append decisions with actor/reason/evidence. Critical fields separately confirmed by accountant.

AI gateway schema version, model ID, prompt hash, provider request ID, confidence source, token cost, latency, redaction policy. Treat uploaded text as untrusted, model no tools or direct DB writes. Structured JSON validation; malformed output retry bounded or NEEDS_INPUT. Missing field stays null/UNKNOWN. Evaluation corpus >=100 representative dossiers across 3 kinds (target), stratified scan quality/language/tables/adjustments; separate calibration/test; report exact match per critical field, evidence locator accuracy, coverage, false PASS, cost and latency. Human labeled source, privacy approval. No dataset or accuracy measured yet.
