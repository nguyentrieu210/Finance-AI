# Rule semantics and policy governance
Outcome PASS/FAIL/UNKNOWN/ERROR/NOT_APPLICABLE; severity BLOCK/WARNING/INFO independent. Applicable false proven -> NOT_APPLICABLE; applicability missing -> UNKNOWN. Comparison on missing, stale, ambiguous or unverified required operand -> UNKNOWN; invalid AST/type/overflow -> ERROR. Boolean AND: false dominates unknown, OR true dominates unknown; NOT unknown stays unknown; ERROR propagates (evaluate bounded operands to preserve evidence). A required blocker FAIL/UNKNOWN/ERROR prevents ready unless policy expressly permits valid waiver for that outcome; ERROR never waived, UNKNOWN on critical financial facts never waived. WARNING FAIL/UNKNOWN requires acknowledgement when policy says; INFO informational. No LLM affects result directly.

Typed registry defines paths, cardinality, source, type, unit/currency, criticality, freshness, access and schema version. AST allows literal/ref, eq/ne/lt/lte/gt/gte, and/or/not, exists, in, sum, add/sub/mul/div, count, all/any over bounded rows, date_diff. No executable code, network, arbitrary paths, unbounded recursion, regex or scripts. Decimal ops checked, divide by zero ERROR, unlike currency/unit disallowed; date clock pinned. Max depth 16, nodes 256, row count 5000 initial draft; exceed -> ERROR. Schema validates shape; compiler validates arity, types, refs, applicability and limits; evaluator records operand evidence. Unknown collection coverage never treated as empty; sum known empty = 0 only if explicit complete set. `exists` false only for known absence. No model call in evaluator.

Policy lifecycle DRAFT→IN_REVIEW→PUBLISHED→RETIRED or REVOKED. Maker/checker independent, no overlap effective scope, all rule clauses linked to approved source, fixtures + simulation + change impact required. Resolution company/kind/effective business date; global fallback only explicit; conflicting policy blocks. Draft never effective. Retired history reproducible; revoked version blocks new handoff until resolved. Form/template/workflow pinned. Simulator compares draft vs existing version on authorized snapshots, outputs outcome transitions, no live writes. AI policy suggestions draft only. Finance owner approves formulas, required docs, thresholds, waiver, signatures and authority. Security approves egress and retention.
