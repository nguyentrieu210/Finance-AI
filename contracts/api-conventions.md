# API conventions and freeze checklist
OpenAPI 3.1 draft, placeholder .invalid servers. DTOs closed; separate commands and read models. All IDs UUID, decimal strings, timestamps RFC3339 UTC; resource scope from authenticated context, never trust tenant header. POST commands require Idempotency-Key; versioned commands If-Match; server returns ETag on versioned resource reads/mutations (document in final OpenAPI freeze). 409 stale/replay mismatch; 422 guard failure. Cursor scoped to filters/tenant, opaque and expiring; maximum 100. List filter schemas, optional fields, response headers and multipart/presigned upload details must be reviewed at G01. Upload intent must enforce checksum, size, MIME and key; finalize verifies bytes and starts quarantine. All downloads authorization and audit. No generic state mutation. DO API option disabled pending live gate. Payment observations only independent verified reference, not self-reported paid flag. Internal modules need no public routes. Form/rule/workflow designer revisions use new draft versions; draft editing and detailed line allocation DTOs require business mapping at G01. No broad object payload or arbitrary additionalProperties. External webhook contracts not invented: X01–X03 gated. Rule DSL external JSON Schema reference resolved relative to OpenAPI file; compiler adds semantic validation.
