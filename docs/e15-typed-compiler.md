# E15 bounded scalar rule compiler
Closed JSON AST subset of approved draft schema: boolean, money and decimal literal/ref, eq/ne/lt/lte/gt/gte, and/or/not, add/sub. Reject unknown refs/operators, wrong arity, incompatible currency/types, invalid literals, nonboolean roots, over-depth/node/byte limits. Evaluates every logical operand to propagate ERROR and preserve references; stale, unverified, missing or evidence-free facts remain UNKNOWN. Records referenced paths and evidence IDs. No external IO/LLM. Unsupported collection/date/quantity/mul/div/exists/in operations fail compilation; no full DSL claim, no actual policy publish, verified source repository or rule-run persistence. Synthetic-only and CI pending.
