# E05 S3 provider capability gate — synthetic-only
GitHub-hosted CI only. The Python harness is an independent executable provider test, not the Rust runtime adapter. MinIO container tag RELEASE.2025-04-22T22-12-26Z is a disposable compatibility baseline, not a supported or security-approved production version; image ID recorded in CI. Use random ephemeral root credentials, two private versioned buckets, loopback only, no host volume. Production provider and IAM remain undecided under D07/D08/D12.

The probe signs PUT with Content-Length, Content-Type, x-amz-checksum-sha256 and If-None-Match; requires signed headers and rejection of wrong bytes, length, MIME, repeated write and expired grants. Reads exact VersionId with bounded length and locally recomputed SHA-256, including after a deliberate test-owner overwrite of the staging alias. Promotes verified bytes through conditional PutObject with If-None-Match: *, tests concurrent exclusive creation, reads exact original version, rejects another overwrite and anonymous reads. Does not silently downgrade if capability is absent. If provider cannot enforce signed bounds, use a separate bounded gateway and validate that instead. See https://docs.aws.amazon.com/AmazonS3/latest/API/API_PutObject.html and https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html.
