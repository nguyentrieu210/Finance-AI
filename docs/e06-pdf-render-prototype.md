# E06 PDF renderer — isolated synthetic candidate
Adds an independent actual Poppler renderer probe to GitHub Actions. Docker build installs distro test binaries; execution is non-root, no network, no bind mounts, read-only filesystem, dropped capabilities, no-new-privileges, bounded RAM/CPU/processes/tmpfs. Each tool process also has CPU/address space/file-size and wall-clock limits. Tests construct their own PDFs with valid xref, two distinct pages and explicit rotation, check byte hash and separate text layers, raster dimensions, malformed input and >200-page rejection. PNG header and dimensions are checked; no claim of complete PNG decoder validation. PDF text and OCR remain unverified candidates. Display-oriented raster needs inverse rotation mapping before source evidence persistence. No production worker, approved model/parser versions, real data, PaddleOCR, bomb corpus, end-to-end scan release, DB result attachment or final acceptance. The base image/distro packages are compatibility test dependencies, not pinned production supply chain. E05 S3 capability remains open. No VPS. CI pending.
