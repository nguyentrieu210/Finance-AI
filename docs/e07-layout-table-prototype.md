Enforces ordered bounded tracks, grid size, cell bounds, exclusive occupied slots, no reused OCR block, and source rectangle containment. Empty or omitted cells remain UNKNOWN; merged slots refer to an anchor only with recognized content. Tests source indexes, overlap, merged cells, missing cells, invalid spans and source reuse.
