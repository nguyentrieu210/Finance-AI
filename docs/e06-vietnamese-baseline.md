# E06 Vietnamese OCR baseline — GitHub only
Independent Tesseract baseline (not a replacement for the specified PaddleOCR adapter). GitHub-hosted runner installs distro Tesseract Vietnamese data, Pillow and DejaVu Sans; creates one synthetic 1800x480 image, runs bounded Tesseract, and passes its TSV into the Rust E06 parser. Test verifies selected expected Vietnamese words/amount and bounded normalized word rectangles. No production documents, no external AI, no VPS. Tesseract version is recorded by CI; model package is a test asset, not approved/pinned production weights. No accuracy claim beyond the fixture.
Rust TSV parser validates one-page header and dimensions, 2 MiB/20k-row/10k-block bounds, numeric coordinates, overflow, confidence basis points, exact outward rectangle normalization and source page number. All results remain human-review candidates. No output release, runtime invocation, source proof, PDF render, PaddleOCR model, deskew, actual cache, DB job attachment, or full E06 acceptance. CI evidence pending. S3 provider remains a failing independent gate (MinIO pull denied); no skip or fallback to synthetic DB pretending to be S3.
