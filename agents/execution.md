# Multi-agent execution
A00 integration lead owns shared contracts, shared types, migrations registry, composition roots and merge gate. A01–A24 own corresponding module. Each worktree branches from approved contract commit. Module code owner must review boundary change; no parallel edits to central Cargo.toml/migrations registry/route aggregator. Reserve migration IDs centrally; additive expand/backfill/contract with rollback strategy. G01 is a real design review, not an arbitrary freeze. Parallel work starts only with approved interfaces, and dependent tasks wait for evidence, not a chat assertion.

DONE record: task ID, branch, commit SHA, requirements/test IDs, exact commands, exit codes, artifact paths, unresolved gaps. BLOCKED record: dependency and next actionable independent task. Merge queue rebases and tests integrated HEAD; conflict owner resolves. No fake integration or bypass CI. Pilot release G04 separate from live integration G05. G04 requires real local DB/storage/OCR and approved model provider (or approved manual extraction mode explicitly labeled degraded), not mocked success. Actual production signoff independent of code completion.
